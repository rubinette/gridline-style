Shared sessions leave beta and arrive on every plan. Read the engineering notes behind them.

Features

  • Shared sessions for people and agents, with per-participant undo and review.
  • Layered settings: defaults, user and project, each value traceable to its layer.
  • The command palette ranks commands by how often you use them.

Breaking changes

  • collab.enabled is replaced by session.allow; old files are migrated on first launch.
