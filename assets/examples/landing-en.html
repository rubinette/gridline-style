Questions

Does my code leave my machine?

Not unless you start a session. Sessions connect peers directly; the relay only helps them find each other.

Can an agent edit while I type?

Yes. An agent joins a session like any collaborator, and its edits merge through the same CRDT as yours.

What happens when two people edit the same line?

Both edits survive in a deterministic order, so every replica ends with the same text.

Is Orbitline a real product?

No. It is a fictional product used to demonstrate gridline-style.
