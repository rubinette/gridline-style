Merging without a referee: the Orbitline sync protocol

Every buffer is a CRDT, so collaborators and agents converge on the same text by identifier, not by position, and no server has to decide who typed first.

01 / System

One buffer, many replicas

A

A session is a set of replicas of the same buffers. Each replica applies its own edits at once and integrates remote ones by identifier, so all of them end with the same text.

The design ruleInput never waits on the network. Merging happens after the keystroke is on screen, never before.

Identifiers, not positions

Each character carries a globally unique, totally ordered identifier; an insert names the character it follows.

Deletes leave tombstones

A delete hides a character instead of removing it, and compaction runs once every replica has seen the delete.

Input

A local edit

Applied immediately to the local replica and stamped with the next clock value.

Transport

Peer to peer

Sent directly to every participant; the relay only helps peers find each other.

Output

A converged buffer

Every replica sorts by (clock, replica) and reads the same text.

02 / Practice

Joining a session

B

A new participant catches up from a snapshot and the operations after it, then edits like everyone else.

01

Snapshot

The owner's replica sends the current buffer and its clock.

02

Replay

Operations newer than the snapshot are applied in identifier order.

03

Edit

The participant receives a replica number and starts typing.

# Join a session and watch it converge
orbit session join render-loop --watch
replica 3 · 1,204 ops replayed · converged
Choosing a data structure is choosing where you are willing to pay for complexity.

Start with one buffer

Share a single file with one collaborator before inviting agents into a whole project.

Keep authority explicit

Convergence is automatic; keeping a change is not. Review stays a deliberate step for the people involved.

Orbitline is a fictional product used to demonstrate gridline-style. Nothing in this brief is a real measurement.
